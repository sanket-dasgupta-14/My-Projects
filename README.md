# My-Projects

## Projects

### [WaysAhead](WaysAhead/)
A transit accessibility API built with FastAPI. It finds nearby bus stops and auto stands from OpenStreetMap, estimates fares and wait times, and tracks trips.

- `WaysAhead/WaysAhead.py`: the whole backend merged into a single file
- `WaysAhead/WaysAhead.html`: front-end page
- `WaysAhead/WaysAhead_Transit_Dataset-6.xlsx`: transit dataset
- `WaysAhead/requirements.txt`: dependencies

Copied from [Soumik-19/WaysAhead](https://github.com/Soumik-19/WaysAhead) (DSC 2155 Lab), original project by Soumik-19.
